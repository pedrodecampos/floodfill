# Algoritmo Flood Fill

Este projeto implementa o algoritmo Flood Fill usando uma pilha, conforme solicitado no trabalho prático.

## Requisitos

- Python 3.6+
- Dependências listadas em `requirements.txt`

## Instalação

1. Clone este repositório
2. Instale as dependências:

```bash
pip install -r requirements.txt
```

## Uso

Execute o script principal:

```bash
python flood_fill.py
```

Isso irá:

1. Criar uma matriz de exemplo com um retângulo
2. Executar o algoritmo Flood Fill a partir do ponto (10,10)
3. Gerar uma animação do processo em `flood_fill_animation.gif`

## Funcionalidades

- Implementação do Flood Fill usando pilha
- Visualização da matriz usando matplotlib
- Geração de animação do processo de preenchimento
- Suporte para matrizes de qualquer tamanho
- Verificação de limites da matriz
- Verificação de cores iguais

## Estrutura do Código

- `flood_fill.py`: Implementação principal do algoritmo
- `requirements.txt`: Dependências do projeto
- `README.md`: Este arquivo
